# Project Rules & Customizations

This file serves as a reference for Gemini/Agent behaviors in this project.

- **Minimalist UI & No Emojis**: Avoid using default HTML emojis (like user, bulb, save icons). Always use proper vector icons (e.g., Phosphor Icons `<i class="ph ph-icon-name"></i>`) to maintain a clean, modern, and professional minimalist blue/white theme.
- **Clear Error Messages (Indonesian)**: Always ensure error messages and validation feedback sent to the user are clear, human-readable, and in Indonesian. Avoid returning raw translation keys (like `validation.unique`).
